# 🎂 Birthday Surprise (React)

1. Open `src/config.js` and put her name, your name, message and reasons.
2. Test locally:  `npm install` then `npm run dev`
3. Put on GitHub:
   - Create a new repo, upload ALL these files (keep the `.github` folder), branch `main`.
   - Repo → Settings → Pages → Source: **GitHub Actions**.
   - Wait ~1 minute (Actions tab) → your link: `https://YOUR-USERNAME.github.io/REPO-NAME/`
4. Send her that link. She sees the surprise instantly — no form.
